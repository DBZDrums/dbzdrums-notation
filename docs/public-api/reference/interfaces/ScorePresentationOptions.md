# Interface: ScorePresentationOptions

Controls which standard score markings are visible in MusicXML and SVG output.

## Properties

### showClef?

```ts
readonly optional showClef?: boolean;
```

Whether to show the percussion clef.

#### Default Value

`true`

---

### showFinalBarline?

```ts
readonly optional showFinalBarline?: boolean;
```

Whether to show the score's final barline.

#### Default Value

`true`

---

### showTimeSignature?

```ts
readonly optional showTimeSignature?: boolean;
```

Whether to show written time signatures.

#### Default Value

`true`
