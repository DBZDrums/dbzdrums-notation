# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.1.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Do not create a public issue for a suspected vulnerability. Use GitHub's **Report a
vulnerability** flow for `DBZDrums/dbzdrums-notation`, including the affected version,
reproduction steps, impact, and any suggested mitigation.

The maintainers will acknowledge a valid report, assess impact, and coordinate a fix and
disclosure timeline with the reporter.
